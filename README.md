# Doomsday Client - Minecraft 1.21.1 Fabric Mod

A comprehensive Minecraft client mod featuring Flight, ESP, X-Ray, Freecam, and Anti-Cheat Bypass systems.

## Features

### Modules
- **Flight** - Move freely through the air
- **ESP** - See player positions and information through walls
- **X-Ray** - See valuable ore blocks through stone
- **Freecam** - Move your camera independently of your player body

### Anti-Cheat Protection
- Human-like delay randomization
- Reach validation (vanilla 4.5 block limit)
- Smooth rotation interpolation
- Position change validation
- Random behavioral patterns
- Packet timing awareness

## Installation

1. Install Fabric Loader 0.16.9+
2. Install Fabric API 0.104.0+1.21.1
3. Place the mod JAR in your mods folder
4. Launch Minecraft

## Usage

- Press **Right Shift** to open the GUI
- Click module names to toggle them on/off
- Close GUI with Escape or the Close button

## Building

```bash
./gradlew clean build
```

The compiled JAR will be in `build/libs/`

## Compatibility

- Minecraft: 1.21.1
- Fabric Loader: 0.16.9+
- Java: 21+
